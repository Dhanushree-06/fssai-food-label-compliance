How the Verification Engine Works

A transparent screening workflow showing which required declarations were detected in the label text

1. OpenCV Vision

Bilateral denoising, Otsu/adaptive binarization, deskewing orientation correction, and HSV veg/non-veg contour analysis.

2. Multi-Tier OCR

PaddleOCR (primary) and EasyOCR with bounding box geometry extraction, confidence mapping, and interactive correction.

3. Label Checks

Each field is marked PRESENT when supported by extracted evidence, otherwise MISSING.

4. Audit Report

Review field findings, coverage, and recommended follow-up actions in a downloadable report.
